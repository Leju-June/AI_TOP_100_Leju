카카오톡 봇

# 튜토리얼

이 문서는 간단히 봇을 만들어볼 수 있는 튜토리얼입니다.

## 개요

- 목표: 봇 API의 [핵심 흐름](이해하기.md#흐름) 확인
- [이벤트 수신 방식](이해하기.md#이벤트%20수신): 공개 URL 없이 로컬에서 실행 가능한 [게이트웨이](게이트웨이.md) 방식 사용
- 선행 작업: [카카오디벨로퍼스 계정 생성](https://developers.kakao.com/docs/ko/tutorial/start), [카카오디벨로퍼스 앱 생성](https://developers.kakao.com/docs/ko/tutorial/start#create)
- 예상 소요 시간: 5분

이 외에 봇에 대한 자세한 설명은 [이해하기](이해하기.md)를 참고합니다.

## 1. 개발 환경 준비하기

##### 최소 요구 사항

- [Python 3.11+](https://www.python.org/)
- [uv](https://docs.astral.sh/uv/)

##### 설치 확인

설치 후 터미널에서 `uv --version`을 실행했을 때 버전이 출력되면 준비된 것입니다. `command not found: uv`가 나오면 아래 중 하나로 설치합니다.

# 설치 스크립트

curl -LsSf https://astral.sh/uv/install.sh | sh

# 또는 Homebrew

brew install uv

## 2. 봇 만들기

1. [앱 관리 페이지](https://developers.kakao.com/console/app)에서 [봇을 생성](설정하기.md#생성필수)합니다.
2. [제품 설정] > [카카오톡 봇] > [봇]에서 **봇 인증 토큰**을 복사합니다.

봇 인증 토큰 복사 화면![](https://developers.kakao.com/docs/_next/image?url=%2Fimg%2Fbot_token_ko.png&w=2040&q=75)

**등록된 웹훅 URL 삭제**

[웹훅 URL](설정하기.md#웹훅)이 등록돼 있으면 게이트웨이 방식을 쓸 수 없습니다. 등록된 웹훅이 있다면 삭제 후 진행합니다.

## 3. 코드 저장하기

작업 폴더를 만들고 `tutorial_echo_bot.py` 파일을 생성합니다.

mkdir -p ~/bot-test

cd ~/bot-test

에디터로 `~/bot-test/tutorial_echo_bot.py`를 연 뒤, 아래 코드를 그대로 붙여넣고 저장합니다.

봇 인증 토큰은 아래 파일에 입력하지 말고, 다음 단계에서 `export`로 설정합니다.

# uv run 시 아래 의존성을 자동 설치합니다 (pip install 불필요)

# /// script

# requires-python = ">=3.11"

# dependencies = ["httpx>=0.27", "websockets>=15.0"]

# ///

import asyncio

import json

import os

import httpx

import websockets

BOT_TOKEN = os.environ["BOT_TOKEN"]

GW_URL = "wss://bot-gateway.kakao.com/gateway"

CALLBACK_URL = "https://kapi.kakao.com/v1/bot/callback"

async def main() -> None:

    async with websockets.connect(GW_URL) as ws:

        # 1. HELLO 받기 → 봇 인증 토큰을 담은 IDENTIFY 보내기 → READY 받기

        hello = await recv(ws)

        await send(ws, {"op": 2, "d": {"token": BOT_TOKEN}})

        await recv(ws)

        print("게이트웨이 연결 성공")

        # 2. HEARTBEAT를 주기적으로 보내 웹소켓 연결을 유지한다

        interval = hello["d"]["heartbeat_interval"] / 1000

        asyncio.create_task(heartbeat(ws, interval))

        # 3. 메시지를 받으면 reply()로 그대로 되돌려준다

        async for raw in ws:

            event = json.loads(raw)

            if event.get("t") == "MESSAGE_CREATE":

                d = event["d"]

                print("RECV:", d.get("content"))

                if d.get("callbackToken"):

                    await reply(d["callbackToken"], d.get("content", ""))

# ----------------------------- 헬퍼 함수 -----------------------------

async def recv(ws) -> dict:

    return json.loads(await ws.recv())

async def send(ws, frame: dict) -> None:

    await ws.send(json.dumps(frame))

async def heartbeat(ws, interval: float) -> None:

    """interval초마다 HEARTBEAT(op=1)를 보내 웹소켓 연결을 유지한다."""

    while True:

        await asyncio.sleep(interval)

        await send(ws, {"op": 1})

async def reply(callback_token: str, text: str) -> None:

    """메시지 콜백 API로 'echo: {받은 메시지}' 답장을 보낸다."""

    body = {

        "skillResponse": {

            "version": "2.0",

            "template": {

                "outputs": [

                    {"simpleText": {"text": f"echo: {text}"}},

                ],

            },

        },

    }

    headers = {

        "Authorization": f"KakaoAK {BOT_TOKEN}",

        "X-Bot-Callback-Token": callback_token,

    }

    async with httpx.AsyncClient() as client:

        resp = await client.post(CALLBACK_URL, json=body, headers=headers)

    print("SENT:", resp.status_code, resp.text)

asyncio.run(main())

## 4. 실행하기

파일이 있는 폴더(`~/bot-test`)에서 터미널을 엽니다.

터미널에서 아래 명령어를 입력합니다. `${봇 인증 토큰}` 자리에 2단계에서 복사한 인증 토큰 값을 넣어 실행합니다.

cd ~/bot-test

export BOT_TOKEN="${봇 인증 토큰}"

uv run --python 3.12 tutorial_echo_bot.py

터미널에 아래 로그가 찍히면 성공적으로 연결된 것입니다. 이 터미널을 켜둔 채 다음 단계를 실행합니다.

게이트웨이 연결 성공

## 5. 결과 확인하기

1. 카카오톡을 실행합니다.
2. 봇 **이름** 또는 **검색용 ID**로 [검색](이해하기.md#발견)하거나, 채팅방에서 봇을 [초대](이해하기.md#초대)합니다.
3. 봇이 있는 채팅방에서 메시지를 보냅니다.
4. `echo: {받은 메시지}` 형태로 답장이 오는지 확인합니다.

에코봇 답장 화면![](https://developers.kakao.com/docs/_next/image?url=%2Fimg%2Fbot_echo_ko.png&w=2040&q=75)

봇을 실행한 터미널에는 아래와 같은 로그가 찍힙니다.

RECV: 안녕하세요                                            # 사용자가 보낸 메시지

SENT: 200 {"totalCount":1,"sendCount":1,"errorCount":0}  # 메시지 콜백 API 응답

게이트웨이 연결이 끊기면 봇을 호출할 수 없습니다. 실제 운영 환경에서는 세션 복구(`RESUME`)까지 구현해야 합니다. [게이트웨이 > 재연결](게이트웨이.md#재연결)과 [전체 예제](게이트웨이.md#에코봇으로%20테스트)를 참고합니다.

## 문제 해결

|증상|원인|해결|
|---|---|---|
|`command not found: uv`|uv가 설치되지 않았거나 PATH에 없습니다.|[개발 환경 준비하기](#1.%20개발%20환경%20준비하기)를 참고해 설치 명령을 실행한 뒤 터미널을 다시 시작합니다.|
|`No such file or directory: tutorial_echo_bot.py`|파일이 없는 폴더에서 실행 중입니다.|`cd ~/bot-test` 후 다시 실행합니다.|
|`KeyError: 'BOT_TOKEN'`|환경 변수가 설정되지 않았습니다.|같은 터미널에서 `export BOT_TOKEN=...`을 다시 실행합니다. 이 명령어는 **현재 터미널 세션**에만 적용됩니다. 터미널을 새로 열면 다시 설정해야 합니다.|
|게이트웨이에 연결되지 않음|[웹훅 URL](설정하기.md#웹훅)이 등록돼 있으면 게이트웨이 방식을 사용할 수 없습니다.|[제품 설정] > [카카오톡 봇] > [봇]에서 등록된 웹훅을 삭제한 뒤 다시 시도합니다.|
|메시지는 받는데(`recv`) 답장이 없음|봇 프로세스가 꺼져 있거나 콜백 API 호출이 실패했을 수 있습니다.|터미널의 `SENT:` 상태 코드와 [에러 코드](에러%20코드.md)를 확인합니다..|
