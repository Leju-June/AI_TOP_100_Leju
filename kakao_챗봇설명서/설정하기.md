카카오톡 봇

# 설정하기

이 문서는 카카오톡 봇 API(이하 '봇 API') 사용 시 필요한 설정에 대해 안내합니다. 카카오톡 봇에 대한 자세한 소개는 [이해하기](이해하기.md)를 참고합니다.

## 봇

[앱 관리 페이지](https://developers.kakao.com/console/app)의 [제품 설정] > [카카오톡 봇] > [봇]에서 카카오톡 봇을 생성하거나 관리할 수 있습니다.

### 생성필수

카카오톡 봇을 제작해 운영하려면 카카오디벨로퍼스 앱이 필요합니다. 아래 절차대로 봇을 생성합니다.

1. 카카오디벨로퍼스 사이트서 [개발자 계정으로 로그인](https://developers.kakao.com/docs/ko/tutorial/start#developer) 후, [카카오디벨로퍼스 앱을 생성](https://developers.kakao.com/docs/ko/tutorial/start#create)합니다.
2. [앱 관리 페이지](https://developers.kakao.com/console/app)의 [제품 설정] > [카카오톡 봇] > [봇]에서 아래 정보를 설정한 후, **[F]** [봇 생성]을 선택합니다.
    
    - 참고: [봇 생성 조건](#봇%20생성%20조건)
    

봇 생성 화면![](https://developers.kakao.com/docs/_next/image?url=%2Fimg%2Fbot_create_ko.png&w=2040&q=75)

**[A] 프로필**: 프로필 정보(아이콘, 이름, 검색용 ID, 설명)를 입력하여 봇 생성 가능

- 참고: 프로필 생성 시 채널이 자동 생성되며, 봇은 채널을 프로필로 사용함

**[B] 아이콘**: 프로필에 사용할 아이콘 이미지 업로드

**[C] 이름(필수)**: 프로필 이름을 10자 이내로 입력, 봇 생성 시 입력한 이름은 이후 수정 불가

**[D] 검색용 ID(필수)**: 프로필 검색시 사용할 ID를 2~15자 사이로 입력, 봇 생성 시 입력한 ID는 이후 수정 불가

- 입력 가능한 문자: 한글, 영문소문자, 숫자, 특수문자(- _), 띄어쓰기 불가 (예: choonsik2)

**[E] 설명**: 20자 이내 입력 가능

##### 봇 생성 조건

- [카카오비즈니스](https://business.kakao.com/)에 가입된 통합 계정이면서 카카오톡 계정과 연결된 카카오디벨로퍼스 계정이어야 합니다.
- 앱 오너 계정이어야 합니다.
- 봇은 앱별로 하나씩만 생성할 수 있습니다.

### 관리

[앱 관리 페이지](https://developers.kakao.com/console/app)의 [제품 설정] > [카카오톡 봇] > [봇]에서 봇 정보를 수정하거나 봇을 삭제할 수 있습니다.

##### 수정

[카카오톡 봇] > [봇]에서 [수정]을 눌러 봇의 아이콘과 설명을 수정할 수 있습니다. 단, 봇의 이름과 검색용 ID는 변경할 수 없습니다.

##### 삭제

[카카오톡 봇] > [봇]에서 [삭제]를 눌러 봇을 삭제할 수 있습니다. 삭제 시 봇에 저장된 웹훅 정보와 봇 인증 토큰이 함께 삭제되며, 카카오톡 채팅방에서도 봇이 제거됩니다.

봇 삭제 시 봇의 이름을 정확히 입력해야 삭제할 수 있으며, 삭제한 봇은 복구할 수 없습니다.

봇 삭제 화면![](https://developers.kakao.com/docs/_next/image?url=%2Fimg%2Fbot_delete_ko.png&w=2040&q=75)

### 인증 토큰

[앱 관리 페이지](https://developers.kakao.com/console/app)의 [제품 설정] > [카카오톡 봇] > [봇]에서 봇 인증 토큰을 복사하거나 관리할 수 있습니다.

**봇 인증 토큰**은 [봇 API](REST%20API.md) 호출이나 [게이트웨이](게이트웨이.md) 연결 시 앱을 식별하고 앱에 등록된 봇의 정보를 확인하기 위해 필요한 **봇 전용** [어드민 키](https://developers.kakao.com/docs/ko/app-setting/app#admin-key)입니다. 이 어드민 키는 봇 API만 호출할 수 있습니다. 봇 API 외에 다른 카카오 API 호출 시에는 다른 어드민 키나 플랫폼 키를 사용해야 합니다.

**필수: 호출 허용 IP 등록**

봇 API를 호출할 수 있는 IP를 지정해야 합니다. [어드민 키 바로가기]를 눌러 [호출 허용 IP](https://developers.kakao.com/docs/ko/app-setting/app#allowed-ip)에서 허용할 IP를 등록합니다.

봇 관리 화면![](https://developers.kakao.com/docs/_next/image?url=%2Fimg%2Fbot_token_ko.png&w=2040&q=75)

##### 복사

[봇 API](REST%20API.md) 호출 시 인증 헤더에 사용할 인증 토큰을 복사합니다.

##### 재발급

인증 토큰을 새로 발급받을 수 있습니다. 재발급 후에는 기존 인증 토큰은 사용할 수 없습니다.

**주의**

토큰 재발급 시 기존 토큰을 사용한 시스템에서 장애가 발생할 수 있으니 주의가 필요합니다.

### 웹훅

[웹훅](웹훅.md) 방식으로 [이벤트를 수신](이해하기.md#이벤트%20수신)하려면, **웹훅 URL**을 반드시 등록해야 합니다.

##### 웹훅 등록

[제품 설정] > [카카오톡 봇] > [봇]에서 [웹훅 등록]을 눌러 아래 정보를 등록합니다.

봇 웹훅 등록 화면![](https://developers.kakao.com/docs/_next/image?url=%2Fimg%2Fbot_webhook_ko.png&w=2040&q=75)

**[A] 웹훅 URL**: 이벤트를 수신할 URL 입력, 공개 URL만 입력 가능, 메서드는 `POST`로 고정  
**[B] 헤더**: 웹훅 인증을 위한 커스텀 헤더 등록, 최대 3개까지 등록 가능

**제약 사항**

- 카카오톡 게이트웨이가 접근 가능한 공개 URL만 입력할 수 있습니다.
- HTTPS 프로토콜만 지원합니다.
- 웹훅 URL 등록 시, [게이트웨이](게이트웨이.md) 방식은 사용할 수 없습니다. 게이트웨이 방식을 사용하려면 등록한 웹훅을 삭제해야 합니다.

##### 웹훅 삭제

[삭제]를 눌러 웹훅을 삭제할 수 있습니다.

## 사용량

[메시지 콜백 API](REST%20API.md#메시지%20콜백)와 [메시지 전송 API](REST%20API.md#메시지%20전송)의 사용량과 사용자 분포를 확인할 수 있습니다.

15일, 30일, 90일 단위로 선택하거나, 원하는 기간을 직접 선택할 수 있습니다. (최대 90일까지 선택 가능)

##### 제공하는 데이터

- 봇 응답 수:
    
    - 사용자 발화 수
    - [메시지 콜백 API](REST%20API.md#메시지%20콜백) 성공 호출 수
    - [메시지 전송 API](REST%20API.md#메시지%20전송) 성공 호출 수
    
- 신규/재방문 분포: 봇을 처음 사용한 사용자와 재방문 사용자의 분포
- 성별 분포: 봇을 호출한 사용자의 성별 분포
- 연령대 분포: 봇을 호출한 사용자의 연령대 분포
