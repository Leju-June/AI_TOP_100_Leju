# 에러 코드

이 문서는 카카오톡 봇 API 이용 중 발생할 수 있는 주요 에러와 해결 방법을 안내합니다.

이 외의 에러는 [공통 에러 코드](https://developers.kakao.com/docs/ko/rest-api/error-code#common)를 참고합니다.

|에러 코드|상태 코드|원인|해결 방법|
|---|---|---|---|
|`-1`|`400`|봇 메타 서버 내부 오류|잠시 후 재시도|
|`-2`|`400`|[도움말 API](REST%20API.md#도움말) 또는 [명령어 API](REST%20API.md#명령어) 요청 시 요청 본문이 형식에 맞지 않는 경우|[명령어 전체 수정 API](REST%20API.md#명령어%20전체%20수정#요청#본문)와 [도움말 수정 API](REST%20API.md#도움말%20수정#요청#본문)의 요청 본문 형식을 확인합니다.|
|`-870`|`400`|[메시지 API](REST%20API.md#메시지) 관련 에러|`extras`에 전달되는 에러 코드별로 다름, [상세 에러 코드](#상세%20에러%20코드) 참고|
|`-871`|`400`|[도움말 API](REST%20API.md#도움말) 관련 에러|`extras`에 전달되는 에러 코드별로 다름, [상세 에러 코드](#상세%20에러%20코드) 참고|
|`-872`|`400`|[명령어 API](REST%20API.md#명령어) 관련 에러|`extras`에 전달되는 에러 코드별로 다름, [상세 에러 코드](#상세%20에러%20코드) 참고|
|`-873`|`400`|유효하지 않는 봇인 경우|봇 생성 및 앱 연동 상태를 확인합니다.|
|`-874`|`400`|명령어 최대 등록 개수(30개)를 초과한 경우|불필요한 명령어를 삭제 후 재시도|
|`-875`|`400`|중복된 명령어가 있는 경우|다른 명령어를 사용합니다.|
|`-876`|`400`|유효하지 않은 키를 사용한 경우|`botUserKey` 또는 `botGroupKey` 중 하나만 입력해야 합니다.  <br>채널 채팅에는 `botUserKey`를 사용해야 합니다. 키 값이 올바른지 확인합니다.|
|`-877`|`400`|채널 채팅에서 채널 친구가 아닌 사용자에게 응답 시도하는 경우|채널 친구한테만 전송할 수 있습니다.|
|`-878`|`400`|말풍선이 유효하지 않은 경우|[말풍선 컴포넌트](REST%20API.md#말풍선%20컴포넌트) 형식을 확인합니다.|
|`-879`|`400`|메시지 전송 수신을 [Off]로 설정한 채팅방인 경우|해당 채팅방의 [봇 설정]에서 [알림메시지 받기]를 활성화합니다.|
|`-880`|`400`|봇이 초대되지 않은 채팅방|채팅방에 봇을 [초대](이해하기.md#초대)합니다.|
|`-881`|`400`|만료된 콜백 토큰을 사용했거나, 이미 사용된 콜백 토큰을 사용한 경우|[콜백 토큰](게이트웨이.md#콜백%20토큰)이 만료되지 않았는지 확인합니다.  <br>콜백 토큰을 새로 발급받아 사용합니다.|

##### 예제

// HTTP/1.1 400 Bad Request

// Content-Type: application/json;charset=UTF-8

{

  "code": -873,

  "msg": "유효하지 않은 봇입니다."

}

## 상세 에러 코드

일부 에러 코드는 `extras` 객체에 상세 에러 코드(`code`)와 메시지(`message`)가 담긴 객체가 함께 전달됩니다.

##### 예제

HTTP/1.1 400 Bad Request

{

    "code": -870,

    "msg": "TalkBotMessageCommonException",

    "extras": {

      "code": "10001",

      "message": "유효하지 않은 앱입니다."

    }

}
