카카오톡 봇

# 이해하기

이 문서는 카카오톡 봇 API(이하 '봇 API')의 개념과 동작 흐름을 소개합니다.

## 기능 소개

봇 API는 카카오톡 채팅방에서 봇이 메시지를 보내는 기능입니다. 봇이 있는 채팅방에서만 허용된 [쿼터](#쿼터) 내에서 사용할 수 있습니다.

![](https://developers.kakao.com/docs/_next/image?url=%2Fimg%2Fbot_intro_ko.png&w=2040&q=75)

**제약 사항**

- 광고 메시지 발송은 불가능합니다.
- [메시지 전송 API](REST%20API.md#메시지%20전송)로 먼저 메시지를 보낼 때는 동일 사용자가 여러 방에서 중복된 메시지를 수신하지 않도록 호출한 사용자를 기준으로 필터링하여 전송하는 것을 권장합니다.

## 사용 방법

아래 순서대로 봇을 준비하고 구현합니다.

1. **봇 준비**: [앱 관리 페이지](https://developers.kakao.com/console/app)에서 카카오디벨로퍼스 앱을 만들고, [봇을 생성](설정하기.md#생성필수)합니다.
    
    - 봇 생성 시 발급되는 [봇 인증 토큰](설정하기.md#인증%20토큰)을 확인합니다. [게이트웨이 연결](게이트웨이.md)과 [REST API](REST%20API.md) 호출 시 인증에 사용합니다.
    
2. **환경 설정**: [이벤트 수신](#이벤트%20수신)을 참고해 어떤 방식으로 이벤트를 수신할지 결정합니다.
    
    - **[게이트웨이](게이트웨이.md)(웹소켓)**: 상시 연결 가능한 환경(워커, 데몬 등) 준비
    - **[웹훅](웹훅.md)(HTTP)**: 이벤트를 전달받을 공개 HTTP URL을 [웹훅 URL](설정하기.md#웹훅)에 등록
    
3. **테스트**: 카카오톡에서 봇을 [검색](#발견)하거나 [초대](#초대)한 뒤, **이벤트 수신부터 메시지 답장까지** [메시지 전송 흐름](#흐름)이 동작하는지 확인합니다. 이 흐름은 에코봇 예제([게이트웨이](게이트웨이.md#에코봇으로%20테스트), [웹훅](웹훅.md#에코봇으로%20테스트))로 한 번에 확인할 수 있습니다.
    
    - **이벤트 수신**: 선택한 방식으로 `DISPATCH` 이벤트를 받습니다.
        
        - 게이트웨이: [웹소켓 프로토콜 흐름](게이트웨이.md#웹소켓%20프로토콜%20흐름)에 따라 연결을 유지하고 [채팅방 이벤트를 수신](게이트웨이.md#채팅방%20이벤트%20수신)합니다.
        - 웹훅: 등록한 웹훅 URL로 전달되는 요청에 **1초 이내**에 `2xx`로 응답합니다. (참고: [채팅방 이벤트 웹훅](웹훅.md#채팅방%20이벤트%20웹훅))
        
    - **메시지 답장**: 사용자 메시지에 답장합니다.
        
        1. [콜백 토큰](게이트웨이.md#콜백%20토큰)(`d.callbackToken`)을 추출합니다. (참고: [MESSAGE_CREATE](게이트웨이.md#MESSAGE_CREATE), [ENTRANCE](게이트웨이.md#ENTRANCE), [CHAT_JOIN](게이트웨이.md#CHAT_JOIN), [AD_REWARD](게이트웨이.md#AD_REWARD))
        2. 답장 내용을 [`SkillResponse`](REST%20API.md#SkillResponse)로 구성합니다.
        3. 봇 인증 토큰과 콜백 토큰으로 [메시지 콜백 API](REST%20API.md#메시지%20콜백)를 호출합니다. 콜백 토큰은 **5분** 내 사용해야 합니다.
        
    
4. 시나리오에 맞게 기능을 구현합니다.
    
    - 말풍선: [말풍선](#말풍선), [말풍선 컴포넌트](REST%20API.md#말풍선%20컴포넌트)
    - 버튼: [플러그인](#플러그인)
    - 추천 발화: [명령어](#명령어), [퀵리플라이](#퀵리플라이)
    - 도움말: [도움말](#도움말), [도움말 API](REST%20API.md#도움말)
    - 봇이 먼저 보내는 메시지: [메시지 전송 API](REST%20API.md#메시지%20전송) (참고: [이용 정책](#이용%20정책))
    

## 메시지 전송

### 흐름

메시지 전송 흐름도![](https://developers.kakao.com/docs/_next/image?url=%2Fimg%2Fbot_sequence_ko.png&w=2040&q=75)

1. 사용자가 봇에게 메시지를 전송합니다. (예: @봇 안녕하세요")
2. 카카오톡 서버가 봇으로 `DISPATCH` 이벤트를 전달합니다. 이 페이로드에 [콜백 토큰](#토큰)이 포함됩니다.
3. 봇이 스킬 응답을 생성합니다. (참고: [SkillResponse](REST%20API.md#SkillResponse))
4. 봇에서 [메시지 콜백 API](REST%20API.md#메시지%20콜백) 호출합니다. 이때 봇 인증 토큰과 봇 콜백 토큰을 함께 전달해야 합니다. (참고: [토큰](#토큰))
5. 봇이 있는 카카오톡 채팅방으로 응답을 전달합니다.

### 토큰

봇 API에는 **인증 토큰**이 필요합니다. [메시지 콜백 API](REST%20API.md#메시지%20콜백)로 응답할 때는 **콜백 토큰**도 함께 필요합니다.

**인증 토큰**은 봇 API 호출이나 게이트웨이 연결 시 인증 헤더에 전달하는 키입니다. 이 토큰으로 앱을 식별하고 앱에 연결된 봇 정보를 확인할 수 있습니다. [앱 관리 페이지](https://developers.kakao.com/console/app)의 [제품 설정] > [카카오톡 봇] > [봇]에서 [확인](설정하기.md#인증%20토큰)할 수 있습니다.

**콜백 토큰**은 [메시지 콜백 API](REST%20API.md#메시지%20콜백) 호출 시 메시지 발송 권한을 검증하기 위해 필요한 토큰입니다. 콜백 토큰은 카카오톡 서버가 봇으로 전달하는 [MESSAGE_CREATE](게이트웨이.md#MESSAGE_CREATE), [ENTRANCE](게이트웨이.md#ENTRANCE), [CHAT_JOIN](게이트웨이.md#CHAT_JOIN), [AD_REWARD](게이트웨이.md#AD_REWARD) 이벤트의 페이로드에 포함되어 있습니다. `d.callbackToken` 값을 추출해 사용합니다.

### 이벤트 수신

채팅방 이벤트(호출, 입장, 퇴장 등)를 봇 서버로 전달하는 방식은 게이트웨이와 웹훅 두 가지입니다. 이벤트 페이로드 형식과 [응답 메시지 발송](REST%20API.md#메시지%20콜백) 방법은 동일하며, 연결 및 수신 방식만 다릅니다.

|구분|게이트웨이(웹소켓)|웹훅(HTTP)|
|---|---|---|
|연결 주체|봇이 카카오톡 서버와 웹소켓으로 연결|카카오톡 서버가 봇 서버로 HTTP POST 요청 전송|
|봇이 제공하는 것|웹소켓 클라이언트|공개 HTTP 엔드포인트|
|이벤트 전달|`op=DISPATCH` 프레임 수신|`op=DISPATCH` JSON 본문 수신|
|연결 유지|`HEARTBEAT`로 직접 [연결 유지](게이트웨이.md#연결%20유지)|불필요|
|재연결|`RESUME` 또는 `IDENTIFY`로 [재연결](게이트웨이.md#재연결)|불필요|
|권장 환경|상시 연결이 가능한 워커, 데몬 환경|서버리스(FaaS) 등 공개 URL 환경|
|참고 문서|[게이트웨이](게이트웨이.md)|[웹훅](웹훅.md)|

## 제공 기능

### 프로필

봇이 채팅방에서 응답할 때 노출되는 프로필입니다.

기존 프로필을 선택하거나 이미지, 이름, 검색용 ID, 설명을 입력하여 새로 [생성](설정하기.md#생성필수)할 수 있습니다.

프로필에 공지, 소식, 카드 등을 추가할 수도 있습니다. [카카오비즈니스](https://business.kakao.com/)에서 추가할 수 있으며, 자세한 방법은 [비즈니스 가이드](https://kakaobusiness.gitbook.io/main/channel/run/mychannel#id-2)를 참고합니다.

### 채팅방

봇 API를 사용할 수 있는 채팅방 종류는 아래와 같습니다. 나와의채팅과 비밀채팅은 지원하지 않습니다.

- 채널채팅
- 일반채팅
- 오픈채팅
- 팀채팅

### 발견

봇을 생성했다면 카카오톡 검색 화면에서 이름이나 검색용 ID를 입력해 검색할 수 있습니다.

봇을 생성한 계정인 경우 채팅방 우측 상단 사이드 메뉴(☰) > [챗봇 beta]에서 봇을 초대할 수 있습니다. 채널채팅은 프로필 홈에서 상단 우측 아이콘을 클릭하여 바로 사용할 수 있습니다.

![](https://developers.kakao.com/docs/_next/image?url=%2Fimg%2Fbot_search_ko.png&w=2040&q=75)

### 초대

사용자가 채팅방에 봇을 초대해야만 봇을 호출할 수 있습니다. 단, 채널채팅은 사용자가 방에 입장한 후 바로 봇을 호출할 수 있습니다.

봇을 채팅방으로 초대하는 카드도 추가할 수 있습니다. 자세한 방법은 [비즈니스 가이드](https://kakaobusiness.gitbook.io/main/channel/run/mychannel#id-2-2)를 참고합니다.

![](https://developers.kakao.com/docs/_next/image?url=%2Fimg%2Fbot_chat_ko.png&w=2040&q=75)

### 말풍선

봇이 응답하는 메시지의 말풍선 종류입니다.

- [SimpleText](REST%20API.md#SimpleText): 텍스트만 포함한 말풍선, (단, 채널채팅은 텍스트 내 @멘션 미지원)
- [SimpleImage](REST%20API.md#SimpleImage): 이미지만 포함한 말풍선
- [TextCard](REST%20API.md#TextCard), [BasicCard](REST%20API.md#BasicCard), [ListCard](REST%20API.md#ListCard), [ItemCard](REST%20API.md#ItemCard), [CommerceCard](REST%20API.md#CommerceCard): 다양한 요소를 조합한 카드 형식의 말풍선
- [Carousel](REST%20API.md#Carousel): 여러 카드를 포함하여 좌우 스와이프할 수 있는 말풍선 (단, 채널채팅만 지원)

지원하는 말풍선![](https://developers.kakao.com/docs/_next/image?url=%2Fimg%2Fbot_chat_bubble_ko.png&w=2040&q=75)

### 명령어

사용자에게 추천할 명령어가 있다면 최대 30개까지 등록할 수 있습니다. [명령어 전체 수정 API](REST%20API.md#명령어%20전체%20수정)로 명령어를 등록합니다.

단, 채널채팅은 [퀵리플라이](#퀵리플라이)를 이용합니다.

![](https://developers.kakao.com/docs/_next/image?url=%2Fimg%2Fbot_command_ko.png&w=2040&q=75)

### 퀵리플라이

채널채팅에서 봇이 응답할 때 다음 액션이나 발화를 제안할 수 있습니다. 사용자가 직접 텍스트를 입력하지 않고도 클릭만으로 봇을 호출할 수 있습니다.

![](https://developers.kakao.com/docs/_next/image?url=%2Fimg%2Fbot_quickreply_ko.png&w=2040&q=75)

### 멘션

봇이 [텍스트 말풍선](#말풍선)을 보낼 때 멘션할 수 있습니다. (예: `@사용자`) 단, 채널채팅은 지원하지 않습니다.

### 도움말

도움말을 등록하여 봇이 제공하는 기능을 자세히 설명할 수 있습니다. 단, 채널채팅은 지원하지 않습니다.

등록한 도움말은 채팅방 우측 상단 메뉴(☰) > [챗봇 beta]에서 개별 봇을 선택하면 확인할 수 있습니다.

![](https://developers.kakao.com/docs/_next/image?url=%2Fimg%2Fbot_guide_ko.png&w=2040&q=75)

### 플러그인

말풍선에 별도로 정의된 액션을 수행할 수 있는 버튼을 추가할 수 있습니다. 지원하는 액션은 아래와 같습니다.

- **메시지 발송**: [Button](REST%20API.md#Button)에서 지정한 `messageText`이 자동 발화됩니다.
- **웹 링크**: 웹 브라우저를 열고 [Button](REST%20API.md#Button)에서 지정한 `webLinkUrl`로 이동합니다.
- **공유**: 현재 메시지를 공유합니다.
- **통화**: [Button](REST%20API.md#Button)에서 정의한 `phoneNumber`로 통화를 연결합니다.
- **상담연결**: 채널 1:1 채팅이나 상담톡을 시작합니다.
- **봇 초대**: 봇을 채팅방에 초대합니다.
- **봇 멘션**: 입력창에 봇 멘션을 입력합니다.
- **멤버 초대**: 현재 채팅방에 멤버를 초대합니다.
- **설정**: 봇 설정 페이지가 열립니다.
- **도움말**: 봇 도움말 페이지가 열립니다.

#### 지원 범위

채팅방 타입별로 플러그인 지원 범위는 아래와 같습니다.

|기능|일반채팅, 오픈채팅, 팀채팅|채널채팅|
|---|---|---|
|메시지 발송|O|O|
|웹 링크|O|O|
|공유|O|O|
|봇 초대|O|X|
|봇 멘션|O|X|
|멤버 초대|O|X|
|설정|O|X|
|도움말|O|X|
|통화|X|O|
|상담연결|X|O|

## 이용 정책

### 쿼터

안정적인 서비스를 제공하기 위해 봇 API는 쿼터를 제한합니다. API별 쿼터는 아래와 같습니다.

|API|쿼터|
|---|---|
|[메시지 전송 API](REST%20API.md#메시지%20전송)|초당 200건  <br>일 1,000건|
|[메시지 콜백 API](REST%20API.md#메시지%20콜백)|초당 200건  <br>일 18,000,000건|
|[명령어 전체 조회 API](REST%20API.md#명령어%20전체%20조회)|초당 20건|
|[명령어 전체 수정 API](REST%20API.md#명령어%20전체%20수정)|초당 20건|
|[도움말 조회 API](REST%20API.md#도움말%20조회)|초당 20건|
|[도움말 수정 API](REST%20API.md#도움말%20수정)|초당 20건|

### 광고 제한

[봇 메시지 API](REST%20API.md#메시지)로 **광고 메시지 발송은 불가**합니다. 정책을 위반하는 경우, **서비스 이용이 제한**되니 유의해야 합니다.
