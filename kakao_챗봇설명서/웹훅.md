카카오톡 봇

# 웹훅

이 문서는 카카오톡 봇 API의 채팅방 이벤트 웹훅을 안내합니다. 서비스에서 카카오 API를 호출하는 방식이 아닌, 카카오톡 서버가 봇으로 전송하는 웹훅 요청에 대한 명세를 설명합니다.

## 시작하기 전에

웹훅을 구현하기 전, 아래 사항을 준비해야 합니다.

1. [앱 관리 페이지](https://developers.kakao.com/console/app)에서 [봇을 생성](설정하기.md#생성필수)합니다.
2. [웹훅을 등록](설정하기.md#웹훅)합니다.

웹훅과 게이트웨이 방식과의 차이는 [이벤트 수신](이해하기.md#이벤트%20수신)을, 웹훅 기능의 전체 흐름은 [메시지 전송 흐름](이해하기.md#메시지%20전송)을 참고합니다.

## 채팅방 이벤트 웹훅

##### 기본 정보

|메서드|URL|[필수 응답 규격](https://developers.kakao.com/docs/ko/getting-started/callback#policy-callback)|인증 방식|
|---|---|---|---|
|`POST`|[앱 관리 페이지](https://developers.kakao.com/console/app)의 [카카오톡 봇] > [봇] > [웹훅]에 등록한 웹훅 URL|HTTP 상태 코드 `2xx`|- [웹훅 설정](설정하기.md#웹훅)에서 등록한 커스텀 헤더|

|요구 사항|참고|
|---|---|
|- [봇 생성](설정하기.md#생성필수)<br>- [웹훅 URL 등록](설정하기.md#웹훅)<br>- [봇 인증 토큰](설정하기.md#인증%20토큰)|- [에러 코드](에러%20코드.md)<br>- [FAQ](https://developers.kakao.com/docs/ko/bot/faq)|

채팅방 이벤트 웹훅은 사용자가 카카오톡에서 봇에게 메시지를 보낼 때, 카카오톡 서버가 `DISPATCH` 이벤트를 봇 서버로 전달하는 기능입니다.

##### 주의 사항

- 웹훅을 수신한 봇 서버는 이벤트 처리를 시작하기 전, HTTP 상태 코드 `2xx`로 **1초 이내**에 응답해야 합니다.
- 웹훅 응답(`204`)은 이벤트 수신 확인용입니다. `MESSAGE_CREATE`처럼 `callbackToken`이 있는 이벤트에만 [메시지 콜백 API](REST%20API.md#메시지%20콜백)로 답장할 수 있습니다. (`LEAVE`처럼 `callbackToken`이 없는 이벤트는 수신 확인만 하면 됩니다.)
- 콜백 토큰(`callbackToken`)이 있으면 만료(**5분**) 전에 [메시지 콜백 API](REST%20API.md#메시지%20콜백)를 호출해야 합니다. 답장 흐름은 [메시지 전송](이해하기.md#메시지%20전송)을 참고합니다.

#### 요청

##### 헤더

|이름|타입|설명|필수|
|---|---|---|---|
|Content-Type|`String`|요청 데이터 타입  <br>`Content-Type: application/json`|O|
|`${CUSTOM_HEADER}`|`String`|[웹훅 설정](설정하기.md#웹훅) 시 등록한 커스텀 헤더  <br>웹훅 요청이 카카오톡 서버에서 온 것인지 검증하는 데 사용|X|

##### 본문

|이름|타입|설명|필수|
|---|---|---|---|
|op|`Integer`|프레임 종류, [게이트웨이 > Opcode](게이트웨이.md#`Opcode`) 참고|O|
|t|`String`|이벤트 종류, [게이트웨이 > 채팅방 이벤트 수신](게이트웨이.md#채팅방%20이벤트%20수신) 참고|O|
|d|`JSON`|이벤트별 페이로드, `t` 값에 따라 `d` 구성 상이, [게이트웨이 > 채팅방 이벤트 수신](게이트웨이.md#채팅방%20이벤트%20수신) 참고|O|

#### 응답

웹훅 요청을 받은 후 **1초 이내** HTTP 상태 코드 `2xx`로 응답합니다. 본문은 포함하지 않습니다.

[메시지 콜백 API](REST%20API.md#메시지%20콜백) 호출은 웹훅 응답 이후 비동기로 처리할 수 있습니다.

#### 예제

아래는 카카오톡 서버가 봇 서버로 보내는 웹훅 요청 예시입니다. 이벤트별 `d` 페이로드는 [게이트웨이 > DISPATCH](게이트웨이.md#DISPATCH)를 참고합니다.

##### 요청

curl -v -X POST "${WEBHOOK_URL}" \

  -H "Content-Type: application/json" \

  -H "${CUSTOM_HEADER_NAME}: ${CUSTOM_HEADER_VALUE}" \

  -d '{

    "op": 0,

    "t": "MESSAGE_CREATE",

    "d": {

      "id": 558185822630215770,

      "content": "안녕하세요",

      "isChannelChatroom": false,

      "botGroupKey": "bgk_xxx",

      "botUserKey": "buk_xxx",

      "timestamp": "2026-06-09T12:34:56.789Z",

      "callbackToken": "cb_token_xxx"

    }

  }'

##### 응답

봇 서버의 엔드포인트에서 카카오톡 서버에 응답해야 할 예시입니다. 모든 이벤트에 공통입니다.

HTTP/1.1 204 No Content

`MESSAGE_CREATE`처럼 `callbackToken`이 포함된 경우, `2xx` 응답 이후 [메시지 콜백 API](REST%20API.md#메시지%20콜백)로 답장할 수 있습니다. 전체 흐름은 [메시지 전송 흐름](이해하기.md#메시지%20전송)을 참고합니다.

curl -X POST "https://kapi.kakao.com/v1/bot/callback" \

  -H "Authorization: KakaoAK ${BOT_TOKEN}" \

  -H "X-Bot-Callback-Token: ${CALLBACK_TOKEN}" \

  -H "Content-Type: application/json" \

  -d '{

    "skillResponse": {

      "version": "2.0",

      "template": {

        "outputs": [

          { "simpleText": { "text": "처리가 완료되었습니다." } }

        ]

      }

    }

  }'

## 에코봇으로 테스트

아래 에코봇은 사용자 메시지를 받아 `echo:` 형태로 되돌려 보내는 최소 예제입니다. `MESSAGE_CREATE`만 처리하며, 웹훅 수신부터 카카오톡 답장까지 [메시지 전송 흐름](이해하기.md#흐름)과 같은 순서로 동작하는지 확인할 수 있습니다. `ENTRANCE`, `CHAT_JOIN`, `LEAVE`는 다루지 않습니다.

이 예제로 다음을 확인할 수 있습니다.

- 등록한 [웹훅 URL](설정하기.md#웹훅)로 `DISPATCH` 이벤트가 잘 도착하는지
- `204` 수신 확인 후 [메시지 콜백 API](REST%20API.md#메시지%20콜백)로 답장이 가는지
- 카카오톡에 `echo: \{원문\}` 형태로 메시지가 오는지

##### 개발 환경

- **Python** 3.11 이상
- **패키지 매니저**: [uv](https://docs.astral.sh/uv/)
- **라이브러리**: `fastapi`, `uvicorn`, `httpx`

### 1. 환경 변수 설정

[앱 관리 페이지](https://developers.kakao.com/console/app)의 [제품 설정] > [카카오톡 봇] > [봇]에서 [봇 인증 토큰](설정하기.md#인증%20토큰)을 확인한 뒤, 아래 환경 변수에 넣습니다.

export BOT_TOKEN="${봇 인증 토큰}"

export WEBHOOK_PORT=8000

### 2. 파일 생성

작업 디렉터리를 만들고 `webhook_echo_bot.py` 파일을 생성해 아래 예제 코드를 저장합니다.

mkdir -p ~/bot-test

앱 관리 페이지에 등록한 [웹훅 URL](설정하기.md#웹훅)(예: `https://your-host/webhook`)로 카카오톡 서버가 `DISPATCH`를 `POST`하는 에코봇 예제입니다.

# /// script

# requires-python = ">=3.11"

# dependencies = [

#     "fastapi>=0.115",

#     "uvicorn>=0.30",

#     "httpx>=0.27",

# ]

# ///

import logging

import os

import sys

import httpx

import uvicorn

from fastapi import FastAPI, Request, Response

logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(message)s")

log = logging.getLogger("echobot")

BOT_TOKEN = os.getenv("BOT_TOKEN")

WEBHOOK_PORT = int(os.getenv("WEBHOOK_PORT", "8000"))

KAKAO_API_URL = "https://kapi.kakao.com"

OP_DISPATCH = 0

app = FastAPI()

@app.post("/webhook")

async def webhook(request: Request) -> Response:

    """게이트웨이가 발송한 DISPATCH 이벤트를 받아 MESSAGE_CREATE만 처리한다."""

    payload = await request.json()

    op, t, d = payload.get("op"), payload.get("t"), payload.get("d", {})

    if op == OP_DISPATCH and t == "MESSAGE_CREATE":

        content = d.get("content", "")

        callback_token = d.get("callbackToken", "")

        log.info("MESSAGE_CREATE — content=%s", content[:100])

        if callback_token:

            await send_callback(callback_token, content)

        else:

            log.error("callbackToken 누락 — skip")

    return Response(status_code=204)

async def send_callback(callback_token: str, text: str) -> None:

    url = f"{KAKAO_API_URL}/v1/bot/callback"

    body = {

        "skillResponse": {

            "version": "2.0",

            "template": {"outputs": [

                {"simpleText": {"text": f"echo: {text}"}},

            ]},

        },

    }

    headers = {

        "X-Bot-Callback-Token": callback_token,

        "Authorization": f"KakaoAK {BOT_TOKEN}",

    }

    async with httpx.AsyncClient() as client:

        resp = await client.post(url, json=body, headers=headers)

    if resp.status_code != 200:

        log.error("callback failed — %d %s", resp.status_code, resp.text)

if __name__ == "__main__":

    if not BOT_TOKEN:

        log.error("BOT_TOKEN 환경변수를 설정하세요")

        sys.exit(1)

    log.info("webhook server listening on port %d", WEBHOOK_PORT)

    uvicorn.run(app, host="0.0.0.0", port=WEBHOOK_PORT)

### 3. 실행 및 동작 확인

터미널에서 아래 명령으로 에코봇을 실행합니다.

uv run ~/bot-test/webhook_echo_bot.py
